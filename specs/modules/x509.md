# Module `lib/x509.bend`

RSA private keys and X.509 certificates (RFC 5280).

## Private keys

`X509/read_rsa_key(input) -> Result(RsaKey, String)` accepts DER or PEM.
`X509/first_key` selects the first block labeled `RSA PRIVATE KEY` or
`PRIVATE KEY` (or the raw DER input); other blocks, such as certificates in a
bundle, are ignored. `X509/rsa_key_der` then reads:

- **PKCS#1** `RSAPrivateKey ::= SEQUENCE { version, n, e, d, p, q, dp, dq,
  qinv }`: recognized when the second element is an INTEGER.
  `X509/rsa_key_pkcs1` requires at least nine INTEGERs.
- **PKCS#8** `PrivateKeyInfo ::= SEQUENCE { version, AlgorithmIdentifier,
  OCTET STRING }`: recognized when the second element is a SEQUENCE; the
  algorithm must be `rsaEncryption` (`1.2.840.113549.1.1.1`) and the OCTET
  STRING holds the PKCS#1 structure.

Errors: `key: no private key found`, `key: encrypted private keys are not
supported` (an `ENCRYPTED PRIVATE KEY` block and no usable key), `key: not a
DER SEQUENCE`, `key: unsupported algorithm (RSA only)`, `key: unrecognized
format (encrypted PKCS#8?)`, `key: invalid RSAPrivateKey`, `key: incomplete
RSAPrivateKey`.

## Certificate files

`X509/cert_ders(input) -> Result(List(der), String)` returns the `CERTIFICATE`
blocks (or the raw DER input) in file order. A file that contains any block
whose label includes `PRIVATE KEY` is rejected with `certificate: the
certificate file must not contain a private key`: every extra certificate is
embedded in the CMS, so a key concatenated to the certificate would otherwise
be published inside the signature. An empty result fails with
`certificate: no certificate found`.

## Certificates

```
type CertInfo:
  New { der, issuer, serial, subject_cn, n, e }
```

`X509/read_cert(input)` reads the first certificate of a PEM or DER input;
`X509/read_cert_der(der) -> Result(CertInfo, String)` reads one DER
certificate and extracts, from `tbsCertificate`:

| Field | Source |
|---|---|
| `der` | Exact encoding of the certificate element (trailing bytes after it are ignored); embedded in the CMS and hashed for `signingCertificateV2`. |
| `serial` | Complete DER INTEGER of `serialNumber` (header included). |
| `issuer` | Complete DER `Name` of the issuer (used verbatim in `IssuerAndSerialNumber`). |
| `subject_cn` | First `commonName` (`2.5.4.3`) attribute of the subject, as UTF-8 (`X509/find_cn`, `X509/text_utf8`). |
| `n`, `e` | Modulus and public exponent from `subjectPublicKeyInfo` (BIT STRING with no unused bits holding `RSAPublicKey`). |

The optional `[0] version` element shifts the positions of the following
fields by one. Error: `certificate: not a DER SEQUENCE`.

String types converted to UTF-8 by `X509/text_utf8(tag, value)`:
UTF8String, PrintableString, IA5String (unchanged), TeletexString/T61String
(treated as ISO-8859-1), BMPString (UTF-16BE) and UniversalString (UTF-32BE).


## Internal helpers

| Function | Purpose |
|---|---|
| `X509/OID_RSA`, `X509/OID_CN` | Encoded OIDs `1.2.840.113549.1.1.1` and `2.5.4.3`. |
| `X509/is_key_label`, `X509/is_cert_label`, `X509/has_secret` | PEM label predicates (`has_secret`: the label contains `PRIVATE KEY`). |
| `X509/any_secret`, `X509/cert_blocks` | Detect secret blocks / collect certificate blocks of a decoded PEM file. |
| `X509/rsa_key_pkcs1(der)` | Reads the nine INTEGERs of an `RSAPrivateKey`. |
| `X509/int_values`, `X509/nth`, `X509/count` | INTEGER contents of a SEQUENCE, list access and length. |
| `X509/find_cn_atv(atvs)` | First `commonName` among the attributes of one RDN. |
